# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(v2.1) as its code of conduct.

**In short:** be respectful and constructive. Harassment, personal attacks, and
discriminatory behavior are not tolerated, in issues, pull requests, or any project
space.

**Enforcement:** the Lead Maintainer is responsible for enforcement and may remove
comments, contributions, or contributors who violate this code. Report concerns
privately to the maintainer (see `SECURITY.md` for contact); reports are handled
confidentially.
