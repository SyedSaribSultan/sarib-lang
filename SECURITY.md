# Security Policy

`.sarib` is research-grade software (v0.1). The reference implementation is designed
to load untrusted files safely (no code execution, bounded expansion, canonical
form — see `stages/09`), but it has not been independently audited.

## Reporting a vulnerability

Please report security issues **privately**, not in a public issue:

- Use GitHub's private vulnerability reporting: the repo's **Security** tab →
  **Report a vulnerability**. This reaches the maintainer directly and confidentially.

Include reproduction steps and the affected version/commit. You'll get an
acknowledgement, and fixes will be credited unless you prefer otherwise.
